Project Information

What: A mini CDN implementation in C++

Why: To understand how real CDNs work at the system level

How: Raw sockets, HTTP protocol, multithreading, caching

Key Learning Outcomes

  • Network programming with sockets
  • HTTP protocol fundamentals
  • Concurrent system design with threads
  • Cache architecture and optimization
  • Distributed system concepts

Testing Commands


# Test origin server
curl localhost:8080/

# Test edge server (first request - cache miss)
curl localhost:8081/

# Test edge server (second request - cache hit)
curl localhost:8081/

# Test multiple files
curl localhost:8082/about.html
curl localhost:8082/style.css
