Welcome to the Mini CDN

A Content Delivery Network built from scratch in C++

What is this?

This is a fully functional CDN (Content Delivery Network) built using raw POSIX sockets and HTTP protocol implementation. It demonstrates how real CDNs like Cloudflare work.

Features

  • ✓ Origin Server (Port 8080) — Master data store
  • ✓ Edge Servers (Ports 8081, 8082) — Cached copies
  • ✓ Intelligent Caching — Cache hits are 30x faster
  • ✓ HTTP/1.1 Implementation — From scratch, no frameworks
  • ✓ Multithreading — Handles concurrent clients
  • ✓ Content-Type Detection — Serves HTML, CSS, JS, images correctly

How It Works

First Request (Cache Miss):

Edge Server → Check Cache → Not Found → Fetch from Origin → Cache Locally → Serve to User

Second Request (Cache Hit):

Edge Server → Check Cache → Found → Serve from Cache (30x faster!)
