Architecture

This mini-CDN consists of three server instances:

Origin Server (8080)

The master data store. All files are stored here in the ./public folder.

Role: Source of truth

Edge Asia (8081)

A cached copy of frequently requested files. Reduces origin load by 30x.

Cache Location: ./cache_asia/

Edge Europe (8082)

Another edge server for geographic distribution simulation.

Cache Location: ./cache_europe/

Technical Implementation

  • Language: C++
  • Network: POSIX Sockets (raw TCP)
  • Protocol: HTTP/1.1 (manually implemented)
  • Concurrency: C++ std::thread (multithreading)
  • Compilation: g++ compiler on Linux/macOS

How Caching Works

Step 1: Check Cache

When a request arrives at an edge server, it first checks if the file exists locally.

Step 2: Cache Hit

If found, serve from local cache (milliseconds). No origin connection needed.

Step 3: Cache Miss

If not found, connect to origin server and fetch the file.

Step 4: Cache & Serve

Save the file locally, then send to the user. Next request will be a cache hit.

Smart Caching Features

  • ✓ Only cache successful responses (200 OK)
  • ✓ Don't cache errors (404, 500)
  • ✓ Automatic Content-Type detection
  • ✓ Path normalization (/ → /index.html)
  • ✓ Security: Prevent path traversal attacks
